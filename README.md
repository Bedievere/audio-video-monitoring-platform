# 音视频监播平台

用于实时监控广播电视和新媒体内容的单机应用系统。

## 功能特性

- 多种音视频源接入（RTSP、RTMP、SRT、HTTP）
- 最多16路实时监看
- 智能异常检测（画面异常、音频异常、信号中断）
- 多渠道告警通知（界面、声音、邮件、即时消息）
- 异常自动录制（异常前30秒、异常后30秒）
- 历史记录查询与导出

## 技术栈

- 前端框架：Electron + React + TypeScript
- 后端服务：Node.js
- 数据库：SQLite
- UI组件库：Ant Design
- 构建工具：Vite

## 使用指南

### 1. 添加音视频源

进入"音视频源管理"页面，点击"添加源"按钮：
- 填写音视频源名称
- 选择协议类型（RTSP/RTMP/SRT/HTTP）
- 输入流地址 URL
- 点击保存

支持的协议示例：
- RTSP: `rtsp://username:password@192.168.1.100:554/stream1`
- RTMP: `rtmp://live.example.com/live/stream`
- SRT: `srt://192.168.1.100:9000?streamid=live`
- HTTP: `http://example.com/stream.m3u8` 或 `http://example.com/stream.mp4`

### 2. 开始监控

进入"实时监控"页面：
- 选择要监控的音视频源
- 点击"开始监控"按钮
- 系统将自动连接并播放视频流

### 3. 配置异常检测阈值

进入"系统设置"页面，可以调整以下检测参数：

| 配置项 | 默认值 | 说明 |
|---------|---------|------|
| 帧率阈值 | 10 fps | 低于此帧率触发告警 |
| 黑屏阈值 | 5 帧 | 连续黑帧数量超过此值触发告警 |
| 画面冻结阈值 | 5000 ms | 画面无变化超过此时间触发告警 |
| 音频静音阈值 | -60 dB | 音量低于此值触发告警 |
| 低码率阈值 | 100 kbps | 码率低于此值触发告警 |
| 高码率阈值 | 10000 kbps | 码率高于此值触发告警 |

调优建议：
- 首次使用建议使用默认配置
- 根据实际运行效果逐步调整
- 避免设置过于严格的阈值导致误报

### 4. 配置告警通知

进入"告警管理"页面，配置多种通知方式：

#### 声音提醒
- 启用/禁用声音告警
- 调整音量（0-100）
- 设置告警音效文件路径

#### 邮件通知
- 启用/禁用邮件通知
- 配置 SMTP 服务器（如 smtp.gmail.com）
- 设置端口（通常为 587）
- 输入发件邮箱和密码（或应用专用密码）
- 添加收件人邮箱列表

#### 即时通讯通知

**钉钉机器人配置：**
1. 在钉钉群设置中添加自定义机器人
2. 获取 Webhook URL
3. 在设置页面选择"钉钉机器人"并填入 URL

**企业微信机器人配置：**
1. 在企业微信群设置中添加机器人
2. 获取 Webhook URL
3. 在设置页面选择"企业微信机器人"并填入 URL

#### 通知频率控制
- 邮件通知间隔：默认 5 分钟（300000ms）
- 即时通讯通知间隔：默认 1 分钟（60000ms）

### 5. 配置异常录制

在"告警管理"页面的"异常录制"选项卡中配置：

| 配置项 | 默认值 | 说明 |
|---------|---------|------|
| 预录制时长 | 5000 ms | 异常发生前录制的时间长度 |
| 后录制时长 | 10000 ms | 异常发生后继续录制的时间长度 |
| 存储路径 | 默认路径 | 录制文件保存位置 |
| 保留天数 | 30 天 | 录制文件自动清理周期 |

### 6. 查看历史记录

进入"历史记录"页面：
- 支持按异常类型筛选
- 支持按日期范围筛选
- 点击"导出数据"可导出为 CSV 文件
- 点击"查看详情"可查看异常详细信息

### 7. 管理录制文件

进入"录制记录"页面：
- 查看所有异常录制文件
- 查看录制统计信息（总数、占用空间、时间范围）
- 点击"详情"可查看录制文件信息
- 点击"删除"可删除单个录制文件
- 点击"清理过期录制"可批量清理过期的文件

## 项目结构

```
workspace/
├── electron/              # Electron 主进程
│   ├── main.ts           # 主进程入口
│   └── preload.ts        # 预加载脚本
├── src/
│   ├── components/        # React 组件
│   │   ├── common/       # 通用组件
│   │   ├── monitoring/   # 监控相关组件
│   │   ├── alerts/       # 告警相关组件
│   │   ├── history/      # 历史记录组件
│   │   └── settings/     # 系统设置组件
│   ├── database/         # 数据库访问层
│   ├── streaming/         # 流解析
│   ├── decoding/          # 视频解码
│   ├── detection/         # 异常检测
│   ├── notification/      # 告警通知
│   ├── recording/         # 录制功能
│   ├── ipc/             # IPC 通信处理
│   ├── services/         # 业务逻辑层
│   ├── types/            # TypeScript 类型定义
│   ├── hooks/           # 自定义 Hooks
│   └── utils/           # 工具函数
├── package.json
├── tsconfig.json
└── vite.config.ts
```
